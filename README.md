# Mapa Cultural - API & Backend

> 🚀 Aplicação interativa focada em usabilidade, gestão de dados e integração de mapas.

## 📋 Sobre o Projeto
O **Mapa Cultural** é um projeto desenvolvido para mapear e facilitar o acesso a pontos culturais, integrando tecnologias web modernas com banco de dados para proporcionar uma experiência fluida e organizada de consulta e gerenciamento de informações.

## 🛠️ Tecnologias Utilizadas
- **JavaScript (ES6+)**
- **Node.js**
- **SQLite**
- **Integração com APIs (Google Maps API)**
- **Git / GitHub**

## ⚙️ Funcionalidades Principais
- [x] Estruturação e manipulação de rotas e dados via backend.
- [x] Integração com banco de dados SQLite para persistência local.
- [x] Conexão com serviços externos para exibição de localizações geográficas.
- [x] Organização limpa de código seguindo boas práticas de desenvolvimento web.

## 🚀 Como Rodar o Projeto localmente
1. Clone este repositório:
   `git clone https://github.com/Luanalvesa/mapa-cultural-api.git`
2. Instale as dependências necessárias (caso utilize Node):
   `npm install`
3. Execute a aplicação:
   `npm start`
